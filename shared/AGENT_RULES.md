# Forge — Agent Rules

1. Understand the task before making changes.
2. Follow the approved architecture.
3. Prefer simple solutions.
4. Make focused changes.
5. Do not modify unrelated files.
6. Test your work.
7. Document important decisions.
8. Record completed and pending work in your handover.
9. Never expose API keys or secrets.
10. Report blockers instead of making risky assumptions.
11. Never claim work is complete without verification.
12. Never merge directly into the main branch.
